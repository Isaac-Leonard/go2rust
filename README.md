## AI Usage
For my fork of the Gosyn crate that this project relies on, AI was used by the project author to review a pull request I made and I did use the LLM generated feedback along with the AI generated test cases to fix issues with my original changes.

I also suspect AI has been further used in writing the code for gosyn before my fork however I have read the majority of the code and have made major modifications so it can be used in this project.

I have not used any AI of my own for writing or reviewing code in this project and do not plan to in the future.
